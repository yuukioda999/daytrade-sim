# AI ログ: 立ち上げ(未決事項の整理、ワイヤーフレーム、ADR)

- 日付: 2026-11-17
- 関連: ADR-0001 から ADR-0007
- 使った AI: Claude(claude-fable-5-2)

## 指示

「米国株デイトレード支援・資産シミュレーター(ローカル完結)」の立ち上げ依頼。最初の5ステップ(未決事項の整理、ADR、初期構成の提案、spec、実装)を、ステップごとに止まってレビューを受けながら進める指示だった。途中で「先にワイヤーフレームを作る」指示が追加された。

## 出力

- 未決事項4点(チャート、保存先、データの境界、Webhook の保存先)の選択肢と推奨
- 依頼文の中で矛盾または未定義だった点の指摘(第1弾の「リアルタイム」、円の元手とドルの株価、損益の出どころ)
- ワイヤーフレーム6枚(ダッシュボード、自動売買の記録、損失が上限に達した時、成績、資産シミュレーター、設定)
- 市場データ提供元の比較(Alpaca、Finnhub、Twelve Data)
- ADR 7本

## 人間が直したこと

- 質問をまとめて出したところ、「質問は1個ずつに」と指示された
- 文章だけで質問したところ、「選択肢がない」と指摘された
- ワイヤーフレームの言葉が専門用語だらけで、「投資初心者なのでわかりにくい」と指摘された。普通の言葉を主にする形に直した
- Discord 通知を設定画面に入れていたが、利用者は Discord を今は使っていなかった。第1弾から通知を外した

## 判断

- 第1弾の内容を変更した。モックデータと手入力の記録から、実際の市場データと自動の練習売買へ(ADR-0001)
- 市場データは Alpaca の15分遅れの全市場データ(ADR-0005)
- 自動売買は画面とは別のプロセスで動かす(ADR-0007)
- 元手は円、為替は固定、端数株あり。1回の買いは元手の50%まで
- リポジトリ名は daytrade-sim。コミット作者は GitHub の noreply アドレス
- 収益化(有料化、証券口座の紹介)は第1弾では行わず、個人の検証とポートフォリオとして作る(2026-11-19)。AI は、法律(投資助言・代理業の登録)と Alpaca のデータ利用条件の2点を、収益化の前に確かめる必要がある点として示した

## AI が間違えた点と学び

| 間違えた点 | どう分かったか | 次からどうするか |
|---|---|---|
| 最初の返答で、推奨4点と確認3点と依頼2点を一度に出した | 人間から「質問は1個ずつ」と指示された | 質問は1回に1つ。選択肢と推奨を付ける。CLAUDE.md に書いた |
| 依頼文の専門用語(ORB、VWAP など)をそのまま画面に並べた | 人間から「わかりにくい」と指摘された | 利用者が誰かを先に確かめる。言い換えの表を CLAUDE.md に置いた |
| 依頼文に Discord があったので、利用者が使っている前提で設計した | 人間から「Discord 使ってない」と言われた | 依頼文に書いてある外部サービスも、今使っているかを確かめる |
| 依頼文の文面どおりに「モックで第1弾」を前提に4点の推奨を出した。利用者の本当の目的(データをためて検証する)を聞いていなかった | ワイヤーフレームの確認中に目的が明らかになり、スコープを決め直した | 未決事項の技術的な選択より先に、何のために使うかを確かめる |
| ワイヤーフレームの数値を2回作り直した(手入力の前提、自動売買の前提) | 上の決め直しの結果 | 画面を作る前に、中心になる動き(誰が売買を記録するか)を確定する |

## 確かめていないこと

- ワイヤーフレームの描画結果。AI はファイルを書いただけで、表示された画面を見ていない。スマホ幅での見え方も見ていない
- Alpaca の利用規約、無料プランの上限の現在の値、日本から練習専用の口座を実際に作れるか
- 各ライブラリの最新版と、組み合わせての動作
- Discord の設定手順のメニュー名(第1弾から外したので、実運用の段階で確かめる)
