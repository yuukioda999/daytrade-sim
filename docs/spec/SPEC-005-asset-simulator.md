# SPEC-005: 資産シミュレーター

- 状態: 承認済み(2026-11-19)
- 日付: 2026-11-19
- 関連する ADR: ADR-0001、ADR-0002

## 目的

1日あたりの想定利益率が一定で続いたと仮定した時の資産の増え方を、3つの条件で比べる。スライダーを動かすと、グラフと年次の表が描き直される。

## 範囲

- 含むもの: 入力、3つの条件の計算、グラフ、年次の表
- 含まないもの: 練習売買の成績との連動

## 入力

| 入力 | 範囲 | 刻み | 既定値 |
|---|---|---|---|
| 最初の元手 | 設定の値(SPEC-006) | なし | 10,000円 |
| お試し期間(利益0で計算) | 0 から 12 か月 | 1 か月(= 20営業日) | 3 か月 |
| 1日あたりの想定利益率 | 0% から 1% | 0.05% | 0.30% |
| 続ける年数 | 1 から 10 年(1年 = 240営業日) | 1 年 | 3 年 |
| 年末に利益から貯金へ回す割合 | 0% から 100% | 5% | 30% |
| 税金(20.315%)を引く | ON / OFF | なし | ON |

## 計算の定義

記号: 元手 P、お試し期間の日数 V(か月 × 20)、利益率 r、年数 Y、貯金へ回す割合 h、税率 T = 0.20315(OFF なら 0)。

運用中のお金 B = P、貯金 S = 0 から始める。年 y = 1 から Y まで:

1. 年の初めの B を B0 とする
2. その年の各営業日 d(1 から 240)について、通算の営業日 g = (y − 1) × 240 + d が V より大きければ B = B × (1 + r)
3. 利益 G = B − B0
4. 税金 = G > 0 なら G × T、そうでなければ 0
5. 税引き後 A = G − 税金
6. 貯金へ回す額 M = A > 0 なら A × h、そうでなければ 0
7. B = B0 + A − M、S = S + M
8. その年の行に、税金、B、S、B + S を書く

3つの条件:

| 条件 | お試し期間 | 貯金へ回す割合 | 税金 |
|---|---|---|---|
| お試し期間あり・貯金あり | 入力の値 | 入力の値 | 入力の ON / OFF |
| お試し期間なし・貯金あり | 0 | 入力の値 | 入力の ON / OFF |
| 全額を再投資 | 0 | 0 | 入力の ON / OFF |

税金は「年末に、その年の利益に課税する」として簡単にしている。損失の繰り越しは計算しない(利益率が0以上なので、年の利益が負になることはない)。

## 計算の例

### 例1: 年末の処理(手計算)

B0 = 10,000、その年の終わりの B = 20,000、税金 ON、h = 30%。

- G = 10,000、税金 = 2,031.5、A = 7,968.5
- M = 7,968.5 × 0.3 = 2,390.55
- B = 10,000 + 7,968.5 − 2,390.55 = 15,577.95、S = 2,390.55、合計 17,968.5

### 例2: 1年分の増え方

P = 10,000、r = 0.30%、V = 0、Y = 1。年の終わりの B(年末の処理の前)= 10,000 × 1.003^240。表計算ソフトで求めた値と、小数2桁まで比べる。

### 境界の例

| 例 | 入力 | 期待する結果 |
|---|---|---|
| 利益率 0% | r = 0 | 毎年 B = P、税金 0、S = 0 |
| 貯金へ回す割合 0% | h = 0、例1 | B = 17,968.5、S = 0 |
| 貯金へ回す割合 100% | h = 100%、例1 | B = 10,000、S = 7,968.5 |
| 税金 OFF | 例1で T = 0 | A = 10,000、M = 3,000、B = 17,000、S = 3,000 |
| お試し期間が運用期間以上 | V = 12 か月(240日)、Y = 1 | 1年目の利益 0 |
| 上限 | r = 1%、Y = 10 | 計算が無限大や非数にならない。画面の数値が枠からはみ出さない |

## 受け入れ基準

| ID | 前提 | 操作またはできごと | 期待する結果 |
|---|---|---|---|
| AC-005-01 | 例1 | 年末の処理を計算する | 例1のとおり |
| AC-005-02 | 例2 | 1年分を計算する | 表計算ソフトの値と小数2桁まで一致 |
| AC-005-03 | 境界の例の各行 | 計算する | 表のとおり |
| AC-005-04 | 既定値 | 画面を開く | 3つの条件の終わりの合計、グラフ、年次の表を出す |
| AC-005-05 | 画面 | スライダーかスイッチを動かす | グラフと年次の表が描き直される |
| AC-005-06 | 画面 | 表示する | 「一定の利益率が毎日続くと仮定した計算で、将来の利益を示すものではない」と出す |
| AC-005-07 | グラフ | 表示する | 3つの条件を色だけでなく線の種類(実線、破線、点線)でも区別する |
| AC-005-08 | スライダー | キーボードで操作する | 矢印キーで値が刻みどおりに変わり、今の値が読み上げられる |

## 決めたこと(2026-11-19、推奨をすべて採用)

なし(お試し期間の単位を「か月 = 20営業日」としたのはワイヤーフレームのとおり)。
