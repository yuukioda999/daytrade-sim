# SPEC-007: 画面の共通の決まりとダッシュボード

- 状態: 承認済み(2026-11-19)
- 日付: 2026-11-19
- 関連する ADR: ADR-0001、ADR-0002、ADR-0005、ADR-0007

## 目的

ワイヤーフレーム(6枚)の画面を作る時の共通の決まりと、ダッシュボードに出すものを決める。各画面の計算は SPEC-002 から SPEC-006 に従う。

## 範囲

- 含むもの: 全画面の共通の決まり、ダッシュボード、自動売買の記録の画面
- 含まないもの: 成績(SPEC-004)、シミュレーター(SPEC-005)、設定(SPEC-006)の中身

## 決めたこと(2026-11-19、推奨をすべて採用)

1. 画面の更新の仕方。採用は「1分ごとに自前の API から読み直す」(データが15分遅れの5分足なので、これ以上早く更新しても変わらない。仕組みが単純)。見送った案は SSE で届いた時に更新する
2. (2026-11-20、T10 のレビュー 7 で人間が「最後に記録した日を出す」(推奨)を選んだ)今日の記録がない時は、最後に記録した日を出す(AC-007-21)。見送った案は、今日の分だけを出す(日本の昼間は画面がほぼ空になる)

## 確かめ方

- AC-007-03: 色の組み合わせを一覧にして、比を計算する単体テスト
- それ以外: 画面のテスト(Playwright)。固定時計と固定データで起動する
- AC-007-04: 幅 390px と 1440px の両方でスクリーンショットを撮り、人間が見て確かめる
