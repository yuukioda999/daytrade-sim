# SPEC-004: 成績

- 状態: 承認済み(2026-11-19)
- 日付: 2026-11-19
- 関連する ADR: ADR-0001、ADR-0004

## 目的

ためた練習売買の結果を日ごとにまとめ、成績の画面に出す。過去データで試した結果は、毎日ためた結果と分けて出す。

## 範囲

- 含むもの: 日ごとの損益と残高、まとめの数値、日ごとの棒グラフと表、過去データで試した結果
- 含まないもの: 複数のルールの比較

## 計算の定義

- その日の損益 = その日に売った分の損益の合計(SPEC-003)
- プラスの日: その日の損益 > 0、マイナスの日: < 0、0円の日: = 0(どちらにも数えず、別に数を出す)
- 一番損した日: その日の損益が最も小さい日。同じ値の日が複数ある時は古い日
- 損失の上限で止まった日: その日に今日の損失の上限に達した日(SPEC-003)
- 合計の損益 = 損益の合計。元手に対する割合 = 合計の損益 / 元手

## 計算の例

| 日付 | その日の損益 |
|---|---|
| 11/02 | +120 |
| 11/03 | −310 |
| 11/04 | 0 |
| 11/05 | −310 |

合計 −500円、元手 10,000円に対して −5.0%。プラス1日、マイナス2日、0円1日。一番損した日は 11/03(−310円、11/05 と同じ値なので古いほう)。

## 受け入れ基準

| ID | 前提 | 操作またはできごと | 期待する結果 |
|---|---|---|---|
| AC-004-01 | 例の4日分 | まとめを計算する | 例のとおり |
| AC-004-02 | 記録が0日 | 成績の画面を開く | 数値の代わりに「まだ記録がありません」と出す |
| AC-004-03 | 今日が取引中 | 成績の画面を開く | 今日の行に「途中」と出す |
| AC-004-04 | 毎日ためた記録と過去データで試した記録がある | 成績の画面を開く | 2つを混ぜずに別の欄に出す |
| AC-004-05 | 成績の画面 | 表示する | 「過去の結果で、これからの利益を示すものではない」と画面の上部に出す |
| AC-004-06 | 棒グラフ | 表示する | プラスとマイナスを色と向き(上下)の両方で区別する。同じ内容を表でも出す |
| AC-004-07 | 「あとから処理」の印がある日(SPEC-003) | 表を表示する | その日に印を出す |
