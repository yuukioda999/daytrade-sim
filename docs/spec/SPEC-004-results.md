# SPEC-004: 成績

- 状態: 承認済み(2026-11-19。2026-11-20 に PR #5 のレビューを受けて、記録のある日と区分の決め方を追記)
- 日付: 2026-11-19
- 関連する ADR: ADR-0001、ADR-0004

## 目的

ためた練習売買の結果を日ごとにまとめ、成績の画面に出す。過去データで試した結果は、毎日ためた結果と分けて出す。

## 範囲

- 含むもの: 日ごとの損益と残高、まとめの数値、日ごとの棒グラフと表、過去データで試した結果
- 含まないもの: 複数のルールの比較

## 計算の定義

- その日の損益 = その日に売った分の損益の合計(SPEC-003)
- 記録のある日: 自動売買が動いていた取引日。売買がなかった日も、その日の損益 0円として行を作る。自動売買が止まっていた日は行を作らない(2026-11-20 追記)
- プラスの日: その日の損益 > 0、マイナスの日: < 0、0円の日: = 0(どちらにも数えず、別に数を出す)。区分は、画面に出すために四捨五入する前の値で決める。小数の計算の誤差(差が 1e-9 以内)は 0 とみなす。そのため +0.3円の日はプラスの日に数え、表の金額は 0円と出ることがある(2026-11-20 追記)
- 一番損した日: その日の損益が最も小さい日。同じ値の日が複数ある時は古い日
- 損失の上限で止まった日: その日に今日の損失の上限に達した日(SPEC-003)
- 合計の損益 = 損益の合計。元手に対する割合 = 合計の損益 / 元手
- 途中で元手を変えた時(2026-11-20 追記。人間が推奨を採用): 元手に対する割合は、一番新しい日の元手で割り、画面に使った元手を出す。日ごとの終わりの残高は、その日に使った元手 + その日までの損益の合計
- 過去データで試した結果(2026-11-20 追記、ADR-0010): 試した時の元手と為替で始め、損益を次の日に引き継ぐ。日ごとの表の日付から、ダッシュボードでその日を見られる(SPEC-007 AC-007-18)

## 計算の例

| 日付 | その日の損益 |
|---|---|
| 11/02 | +120 |
| 11/03 | −310 |
| 11/04 | 0 |
| 11/05 | −310 |

合計 −500円、元手 10,000円に対して −5.0%。プラス1日、マイナス2日、0円1日。一番損した日は 11/03(−310円、11/05 と同じ値なので古いほう)。
