# SPEC-XXX: (機能の名前)

- 状態: 下書き / レビュー待ち / 承認済み
- 日付: YYYY-MM-DD
- 関連する ADR: ADR-XXXX

## 目的

この機能で、誰が何をできるようになるか。

## 範囲

- 含むもの
- 含まないもの

## 用語

画面の言葉と専門用語の対応は CLAUDE.md の表に従う。この spec だけの用語があれば書く。

## 受け入れ基準

ID は `AC-(spec 番号)-(連番)`。1つの基準に、確かめられる条件を1つだけ書く。

| ID | 前提 | 操作またはできごと | 期待する結果 |
|---|---|---|---|
| AC-XXX-01 | | | |

## 計算の定義

式と、手計算した例を書く。境界の値、0%、上限の例を含める。

| 例 | 入力 | 期待する値 | 計算の過程 |
|---|---|---|---|
| | | | |

## 決まっていないこと

人間の判断が必要な点。選択肢と推奨を付ける。決まったらこの節から消し、必要なら ADR に書く。

## 確かめ方

受け入れ基準ごとに、どのテスト(単体、画面)で確かめるか。
