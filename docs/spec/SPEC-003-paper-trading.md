# SPEC-003: 自動の練習売買

- 状態: 承認済み(2026-11-19)
- 日付: 2026-11-19
- 関連する ADR: ADR-0001、ADR-0004、ADR-0007

## 目的

買いサイン(SPEC-002)どおりに練習の買いを記録し、決めたルールで練習の売りを記録する。実際の注文は出さない。

## 範囲

- 含むもの: 買う量と価格、売る条件と価格、損益、今日の損失の上限、残高、止まっていた時間の扱い
- 含まないもの: 実際の発注、手数料と税金(税金はシミュレーターだけで扱う)

## 計算の定義

記号: 元手 P(円)、為替レート fx(円/ドル、設定値)、株数 q、買値 e、売値 x。

1. 買う価格: 買いサインが出た足の次の足の始値(決めたこと 1)
2. 買う量: 予算 = min(P × 50%, 買いに使える残り)。q = 予算 / (買値 × fx) を小数4桁で切り捨てる。q が 0 になる時は買わない
3. 買いに使える残り = 残高 − 持っている株の買付額の合計(円)
4. 損切りの価格: s = L_orb(朝の安値。決めたこと 2)
5. 利益を守る売りの目安: 買ってからの最高値 m が e × 1.05 以上になったら有効にし、目安 t = m × 0.97
6. 売る判定(買った足から、足ごとに):
   - その時点の売りの基準 = 利益を守る売りの目安が有効なら max(s, t)、そうでなければ s
   - 足の安値 ≤ 売りの基準 なら売る。売値 = min(売りの基準, 足の始値)(始値で基準を下回っていた時は始値で売れたものとする)
   - m は、売る判定のあとで、その足の高値で更新する(1本の足の中で高値と安値のどちらが先かは分からないため、不利な側に倒す)
   - その日の最後の足の終値で、残っている株を売る
7. 損益(円) = (x − e) × q × fx。内部は小数のまま持ち、画面では1円未満を四捨五入して出す
8. 残高 = P + これまでの損益の合計。日をまたいで引き継ぐ
9. 今日の損失の上限: P × 10%。今日の売り終わった分の損益の合計が −(P × 10%) 以下になったら、その日は新しく買わない(決めたこと 3)。持っている株の売りの判定は続ける
10. 同じ足を2回処理しても、記録は1回だけにする
11. 止まっていた時間: 再び動いた時に、その間の足を取り直して順に処理し、止まっていなかった場合と同じ記録を作る(決めたこと 4)。あとから処理した記録には印を付ける

## 計算の例

為替 fx = 150、元手 P = 10,000円。

### 例1: 買う量

予算 5,000円、買値 $78.45。q = 5,000 / (78.45 × 150) = 5,000 / 11,767.5 = 0.42489... を切り捨てて 0.4248株。買付額 = 0.4248 × 11,767.5 = 4,998.834円。

### 例2: 損切り

例1の買い、損切りの価格 $77.10。ある足が 始値 77.50、安値 77.00。安値 77.00 ≤ 77.10 なので売る。売値 = min(77.10, 77.50) = 77.10。損益 = (77.10 − 78.45) × 0.4248 × 150 = −1.35 × 63.72 = −86.022 で、画面は −86円。

### 例3: 始値で損切りの価格を下回った

例1の買い。ある足が 始値 76.90、安値 76.50。売値 = min(77.10, 76.90) = 76.90。損益 = (76.90 − 78.45) × 63.72 = −98.766 で、画面は −99円。

### 例4: 利益を守る売り

買値 $25.00、予算 5,000円。q = 5,000 / 3,750 = 1.33333... で 1.3333株。最高値 m が $26.80 に達した(26.80 ≥ 26.25 なので有効)。目安 t = 26.80 × 0.97 = 25.996。損切りの価格 s が $24.50 なら、売りの基準 = max(24.50, 25.996) = 25.996。次の足が 始値 26.30、安値 25.90 なので売る。売値 25.996。損益 = 0.996 × 1.3333 × 150 = 199.195 で、画面は 199円。

### 境界の例

| 例 | 入力 | 期待する結果 |
|---|---|---|
| 最高値がちょうど +5% | e = 25.00、m = 26.25 | 有効になる。目安 = 25.4625 |
| 最高値が +5% 未満 | e = 25.00、m = 26.24 | 有効にならない |
| 安値が売りの基準と同じ | 安値 = 77.10、基準 = 77.10 | 売る |
| 今日の損失がちょうど上限 | 今日の売り終わった分 = −1,000円 | その日は新しく買わない |
| 今日の損失が上限の手前 | −999円 | 新しく買う |
| 予算が足りない | 買いに使える残り = 0円 | 買わない |
| 利益0% | 売値 = 買値 | 損益 0円 |

## 決めたこと(2026-11-19、推奨をすべて採用)

1. 買う価格。採用は「買いサインが出た足の次の足の始値」(足が終わってから注文する実際の流れに近い)。見送った案の「買いサインが出た足の終値」は、その価格を知った時点ではもう買えないので、成績が良く出すぎる
2. 損切りの価格。採用は「朝の安値」(朝の高値超えを使う手法で一般的。ワイヤーフレームと同じ)。見送った案は「買値から一定の割合(例: −2%)」で、損失の幅が銘柄によらずそろう
3. 今日の損失の上限で数える損益。採用は「売り終わった分だけ」(値動きの途中で止まったり再開したりしない)。見送った案は「持っている株の損益も含める」(上限の守りは固くなるが、判定が揺れる)
4. 止まっていた時間の扱い。採用は「取り直して順に処理する」(データは15分遅れなので、もともと少し遅れて処理している。結果が止まったかどうかに左右されない)。見送った案は「止まっていた間は売買しない」(実際に見ていなかった時間を記録しないので、運用の実態には近い)
5. 1回の買いの予算の元。採用は「元手の50%(固定で 5,000円)」(ワイヤーフレームと同じ)。見送った案は「残高の50%」(勝つと増え、負けると減る)
6. 手数料。採用は「0円として計算し、画面と README に手数料を含まないと書く」。見送った案は1回あたりの手数料を設定できるようにする(機能が増える)
