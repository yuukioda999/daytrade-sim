# SPEC-002: 買いサインの判定

- 状態: 承認済み(2026-11-19)
- 日付: 2026-11-19
- 関連する ADR: ADR-0004、ADR-0005

## 目的

監視している4銘柄(SOXL、TQQQ、TSLL、NVDL)について、3つの条件がそろったかを足ごとに判定し、買いサインを出す。

## 範囲

- 含むもの: 3つの条件の計算と判定、買いサインの発生
- 含まないもの: 売買の記録(SPEC-003)

## 用語

| 画面の言葉 | 専門用語 | この spec での記号 |
|---|---|---|
| 朝の高値 / 朝の安値 | ORB の高値 / 安値 | H_orb / L_orb |
| 今日の平均価格 | VWAP | VWAP_t |
| 取引量 | 出来高 | v_t |

## 計算の定義

使う足は5分足(決めたこと 1)。足 t は、始値 O_t、高値 H_t、安値 L_t、終値 C_t、取引量 v_t、その足の平均約定価格 p_t を持つ。p_t は Alpaca の足に含まれる値を使い、ない場合は (H_t + L_t + C_t) / 3 とする。

1. 朝の高値と安値: 朝の値幅の時間(SPEC-001)の3本について、H_orb = 高値の最大、L_orb = 安値の最小
2. 条件1「朝の高値超え」: C_t > H_orb(等しい時は満たさない)
3. 条件2「今日の平均価格より上」: VWAP_t = Σ(p_i × v_i) / Σ v_i(i は 09:30 の足から t まで)。C_t > VWAP_t。Σ v_i が 0 の時は満たさない
4. 条件3「取引量の増加」: 基準 = 過去20取引日の、同じ時刻に始まる足の取引量の平均(決めたこと 2)。v_t ≥ 基準 × 1.5。過去の取引日が20日に満たない時は、ある日数で平均する。0日の時は満たさない
5. 買いサイン: 09:45 以降、新しい買いの締め切り(SPEC-001)より前に始まった足 t で、3つの条件がすべて満たされた時。足が終わった時点(終値が決まった時点)で判定する
6. 買いサインは1銘柄につき1日1回まで(決めたこと 3)

## 計算の例

### 例1: 買いサインが出る

| 足の開始 | 高値 | 安値 | 終値 | 取引量 | 平均約定価格 |
|---|---|---|---|---|---|
| 09:30 | 77.70 | 77.10 | 77.55 | 100 | 77.40 |
| 09:35 | 77.90 | 77.40 | 77.60 | 70 | 77.65 |
| 09:40 | 77.85 | 77.35 | 77.45 | 55 | 77.60 |
| 09:45 | 78.05 | 77.70 | 78.00 | 120 | 77.90 |

09:45 の足の過去20取引日の平均取引量は 60 とする。

- H_orb = max(77.70, 77.90, 77.85) = 77.90、L_orb = min(77.10, 77.40, 77.35) = 77.10
- 条件1: 78.00 > 77.90 なので満たす
- 条件2: Σ(p × v) = 77.40×100 + 77.65×70 + 77.60×55 + 77.90×120 = 7,740 + 5,435.5 + 4,268 + 9,348 = 26,791.5。Σv = 345。VWAP = 26,791.5 / 345 = 77.65652...。78.00 > 77.6565 なので満たす
- 条件3: 60 × 1.5 = 90。120 ≥ 90 なので満たす
- 買いサインが出る

### 境界の例

| 例 | 入力 | 期待する結果 |
|---|---|---|
| 終値が朝の高値と同じ | C_t = 77.90、H_orb = 77.90 | 条件1を満たさない |
| 取引量がちょうど1.5倍 | v_t = 90、基準 = 60 | 条件3を満たす |
| 過去の取引日が0日 | 基準を計算できない | 条件3を満たさない |
| 今日の取引量の合計が0 | Σ v = 0 | 条件2を満たさない |
| 朝の値幅の時間の足 | 09:40 の足 | 3条件がそろっても買いサインは出ない |
| 締め切り以降の足 | 15:30 の足 | 買いサインは出ない |
| 2回目の条件成立 | 同じ日に同じ銘柄で再び3条件がそろう | 買いサインは出ない(1日1回) |

## 決めたこと(2026-11-19、推奨をすべて採用)

1. 判定に使う足の長さ。採用は5分足(ワイヤーフレームと同じ。データの量が少ない)。1分足は判定が細かくなるが、取得と保存の量が5倍になる
2. 取引量の基準。採用は「過去20取引日の同じ時刻の足の平均」(画面の「ふだんの1.5倍」と意味が合う)。見送った案は「今日の 09:30 から直前の足までの平均」(過去データが要らないが、取引開始直後は取引量が多く、昼以降は条件を満たしにくくなる)
3. 1日の買いサインの回数。採用は1銘柄1日1回(朝の高値超えを使う手法の一般的な形。売買の回数が増えすぎない)
