# 公開の判断の材料

- 日付: 2026-11-20(T12)
- 決める人: 人間(作者)。リポジトリを公開に切り替えるのも人間が行う(AI の作業環境からは、リポジトリの設定を変えられない)

リポジトリは今、非公開です。公開するかを決めるために、AI が確かめたことと、確かめていないことを書きます。

## 確かめたこと

| 観点 | 確かめた方法 | 結果 |
|---|---|---|
| 接続用キーなどの秘密 | CI の gitleaks がリポジトリの全履歴を調べる(PR #12 のマージまで毎回成功)。検査が働くことも、偽のキーで毎回確かめている | 見つかっていない。テストのダミーのキーだけが、決めた形で除外されている |
| コミットしてはいけないファイル | CI で `data/`、`.db`、`.env` が入っていないことを確かめる。`.env.example` はダミー値だけ | 入っていない |
| 個人のメールアドレス | 全コミットの作者とコミッター、全履歴の差分を検索した | 作者は GitHub の noreply のアドレス、コミッターは GitHub(マージ)と noreply だけ。個人のメールアドレスは見つからなかった |
| 住所などの個人の情報 | リポジトリの全ファイルを、住所や連絡先の言葉で検索した | 見つからなかった。作者の名前(小田裕貴)は、コミットの作者、LICENSE、CLAUDE.md にある |
| 市場データ | `data/` はコミットしない。README の画面の画像は、画面のテスト用の作り物のデータで撮った | Alpaca から取った値動きは入っていない |
| 使っている部品のライセンス | Lightweight Charts(Apache-2.0)は、チャートの上の帰属表示(ADR-0002)。ほかの依存は npm から入れるだけで、リポジトリに含めていない | 帰属表示は画面のテストで確かめている(AC-007-13) |
| ライセンス | 人間が MIT を選んだ(2026-11-20)。無保証と、責任を負わないことが書かれる | LICENSE を足した |
| 免責 | 全画面の下部、成績の画面の上部、README に、投資助言ではないこと、将来の利益を示さないことを書いている | 画面のテストで確かめている(AC-007-01、AC-004-05) |
| アクセシビリティ | 色の比の単体テスト。仕上げで axe-core(WCAG 2.1 AA の規則)を全6画面、デスクトップとスマホの幅で動かした | 1件(読み上げから外したグラフの中のフォーカス)を見つけて直した。直したあとは0件(テスト用のデータで) |
| スマホの幅 | 画面のテストで、全画面が 390px で横にはみ出さないこと、表が枠の中で横に動かせることを確かめる | 成功 |

## 公開すると見えるもの(知っておくこと)

- コミットの説明の最後に、AI の作業の記録へのリンク(Claude-Session)がある。リンク先は作者のアカウントでしか開けない
- docs/ai-log に、AI が間違えた点、人間とのやりとりの要点が書いてある。良く見せすぎないように書いている
- プルリクエストの本文(AI レビューの指摘と人間の判断)も公開される
- 作者の名前が LICENSE、コミット、CLAUDE.md に出る

## 確かめていないこと

- 本物の市場データをためた状態での画面と成績(作者の Mac で動いている)
- Safari での見え方(画面のテストは Chrome だけ)
- 公開したあとに、README の画像と表が GitHub でどう見えるか

## 公開する時の手順(人間が行う)

1. この PR(T12)をマージする
2. GitHub のリポジトリの Settings で、Visibility を Public にする
3. 公開したあとに、README の画像と表が GitHub で正しく出ることを見る
4. 公開しない場合は、この文書に「非公開のまま」と理由を書き足す
