# ADR-0005: 市場データの提供元

- 状態: 承認済み(2026-11-17)
- 日付: 2026-11-17

## 背景

4銘柄の5分足(または1分足)と取引量を、毎日の取引時間中に取り続ける。過去データも同じ形で取りたい。費用はかけない。

## 選択肢と評価

2026-11-17 に検索して得た情報による。提供元の登録画面や契約画面で確かめたものではない。

| 案 | 無料枠 | 評価 |
|---|---|---|
| A: Alpaca | 15分以上前なら全市場分のデータを取れる。リアルタイムは IEX(1つの取引所)の分だけ。過去データは2016年以降。毎分200回まで | 過去データと毎日のデータを1つの接続で取れる。練習専用の口座はメールアドレスだけで作れる |
| B: Finnhub | 毎分60回 | 株価の足データが無料枠に含まれない。この用途では使えない |
| C: Twelve Data | 毎分8クレジット、1日800まで | 4銘柄を1分ごとに取ると1日の上限を超える。過去データを大量に取るには足りない |

## 決定

A。Alpaca の無料プランで、15分遅れの全市場データを使う。

## Alpaca の中での選択

| 案 | 評価 |
|---|---|
| 15分遅れの全市場データ(採用) | 取引量と今日の平均価格が全市場分で計算でき、条件の判定が実際に近い。画面の表示は15分前の値になる |
| IEX のリアルタイム | 画面は今の値になる。取引量が実際のごく一部で、取引量と平均価格の条件が実際とずれる |

## 理由

- 実際の注文を出さないので、15分の遅れは練習売買の成績に影響しない
- 3つの条件のうち2つ(取引量、今日の平均価格)は取引量に依存する。一部の取引所だけの数字では判定が変わる

## 影響

- ダッシュボードに「15分遅れ」と明記する
- 実運用の段階(実際に売買の参考にする段階)では、15分遅れのままでは使えない。その時点で有料のリアルタイムデータを含めて決め直す
- 接続用キーは秘密として扱う(ADR-0006)
- 無料枠の条件が変わると動かなくなる。取得に失敗した時は、画面に「データを取得できていない」と出し、その間は練習売買を行わない

## 確認していないこと

- Alpaca の利用規約で、個人の検証用途と、取得したデータを使った画面のスクリーンショットを GitHub に載せることが許されるか
- 足データに含まれる項目(出来高加重平均価格が足ごとに付くか)
- 無料プランの上限の現在の正確な値
- 日本から練習専用の口座を作れること(公式の説明では国を問わないとあるが、実際の登録では試していない)
