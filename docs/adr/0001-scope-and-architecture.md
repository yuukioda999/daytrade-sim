# ADR-0001: 第1弾のスコープと全体構成

- 状態: 承認済み(2026-11-17)
- 日付: 2026-11-17
- 決めた人: 小田裕貴(選択肢と推奨は AI が提示)

## 背景

当初の依頼は「モックデータで動く、ローカル完結のデイトレード支援と資産シミュレーション」だった。ワイヤーフレームの確認中に、目的が「実際のデータをためて、自動で練習売買を行い、成績を蓄積する」に変わった。実装前に決め直した内容をここに残す。

## 当初の依頼から変えたこと

| 項目 | 当初 | 決め直し後 | 理由 |
|---|---|---|---|
| データ | モック。実データは第2弾 | 実際の市場データと過去データを第1弾で使う | 作り物のデータでは、たまった成績が判断材料にならない |
| 売買の記録 | 画面のシグナル表示だけ | 買いサインどおりにアプリが自動で練習売買を記録する | データ蓄積の期間に、人が張り付かずに検証するため |
| 通知 | Web Notifications、Web Audio、Discord | 第1弾はなし。Discord は実運用の段階で入れる | 利用者が Discord を今は使っておらず、蓄積の期間は通知が不要 |
| 外部との通信 | Discord の Webhook への送信だけ | 市場データ提供元(Alpaca)からの取得だけ | 上の2点の結果 |
| 画面の言葉 | 専門用語(ORB、VWAP など) | 普通の言葉を主にして、専門用語は添える | 利用者が投資初心者で、専門用語だけでは読めない |

## 第1弾のスコープ

1. ダッシュボード: 監視リスト(SOXL、TQQQ、TSLL、NVDL)、3つの条件の達成状況、5分足チャート、買いサイン、今日のお金の状況
2. 自動の練習売買: 買いサインで買い、損切りの価格、利益を守る売りの目安、取引終了のいずれかで売る。記録を保存する
3. 成績: 日ごとの損益、プラスとマイナスの日数、過去データで試した結果
4. 資産シミュレーター: 当初の依頼どおり
5. 設定: 自動売買の ON/OFF、市場データの接続、過去データの取り込み、元手と為替
6. README: アーキテクチャ、セットアップ、機能一覧、免責事項

## やらないこと

- 実際の発注、証券会社との接続。Alpaca には練習用の発注 API もあるが使わない。売買の計算と記録はこのアプリの中だけで行う
- 通知(第1弾)
- 複数の売買ルールの比較

## このアプリの位置づけ

個人の検証とポートフォリオとして作る(2026-11-19 に確認)。

- 有料での提供と、証券口座の紹介(アフィリエイト)は第1弾では行わない。練習売買の成績がたまってから、別の ADR で検討する
- 検討する時に確かめること: 投資助言・代理業の登録が要るか(会員制の自動売買ソフトは一般に登録が必要とされる)、Alpaca のデータの商用利用と再配布の条件
- ADR-0005 の Alpaca の選定は、個人の非商用利用を前提にしている。収益化する場合はデータの提供元から決め直す

## 売買に関する決定

| 項目 | 決定 |
|---|---|
| 元手と通貨 | 元手は円(既定 10,000円)。為替レートは設定値(固定)。端数株あり |
| 1回の買いに使う金額 | 元手の50%まで |
| 買い | 3つの条件(朝の高値超え、今日の平均価格より上、取引量の増加)がそろったら買う |
| 売り | 損切りの価格に達した時、利益が5%を超えたあと最高値から3%下がった時、その日の取引終了時 |
| 今日の損失の上限 | 元手の10%。達したらその日は買わない |

## 全体構成

- Next.js(App Router)と TypeScript。UI は Tailwind CSS、shadcn/ui、Lucide React
- 層を4つに分ける
  - domain: 条件の判定、損益、損失の上限、複利と税金の計算。副作用のない純粋関数
  - application: ユースケース(足を受け取って判定し、練習売買を記録する、など)
  - infrastructure: 市場データ、保存、時計、市場カレンダーのアダプタ
  - app: 画面と Route Handler
- 画面は自前の API だけを呼ぶ。外部の API を直接呼ばない(ADR-0004)

## 影響

- 第1弾の作業量が当初より増える
- 実データをためるには、米国市場が開いている間、利用者の Mac でアプリを動かし続ける必要がある(ADR-0007)
- 「ローカル完結」ではなくなる。README にも外部との通信先を明記する

## spec で決めること(仮置きのもの)

以下はワイヤーフレーム作成時に AI が仮に置いた。確認が済んでいない。

- 損切りの価格は「朝の値幅(取引開始から15分)の安値」
- 取引量の増加の基準は「1.5倍」。何に対する1.5倍かも未定義
- 今日の損失が上限に達したあとも、持っている株の売りは続ける
- 練習売買の約定価格をどの値にするか(条件がそろった足の終値など)
- シミュレーターの「検証なし」は「ヘッジあり」として計算する。税金は年末に利益へ課税する
