# ADR-0002: チャートのライブラリ

- 状態: 承認済み(2026-11-17)
- 日付: 2026-11-17

## 背景

チャートは2種類ある。ダッシュボードの価格チャート(5分足のローソク足に、朝の値幅と今日の平均価格を重ねる)と、資産シミュレーターと成績のグラフ(折れ線、棒)。

## 選択肢と評価

| 案 | 価格チャート | シミュレーターのグラフ | 評価 |
|---|---|---|---|
| A: Recharts だけ | ローソク足は標準になく自作が必要 | 向いている | 価格チャートの自作ぶんがテストと保守の負担になる |
| B: Lightweight Charts だけ | 向いている | 横軸が年次の比較グラフには不向き | シミュレーター側が不自然な実装になる |
| C: 用途で使い分ける | Lightweight Charts | Recharts | 依存が2つになる。それぞれ得意な用途で使える |

## 決定

C。価格チャートは TradingView Lightweight Charts、シミュレーターと成績のグラフは Recharts を使う。

## 理由

- 価格チャートは時系列の金融データに特化したライブラリのほうが、ローソク足、価格の線、時間軸の扱いを自作せずに済む
- シミュレーターは複数系列の比較と年次の表示で、汎用のグラフライブラリが合う

## 影響

- Lightweight Charts は Apache-2.0 で、TradingView を制作者として示すことが求められる。チャート上の帰属表示(attributionLogo)を有効にし、受け入れ基準に入れる
- Lightweight Charts は canvas 描画で、DOM を直接扱う。React では描画用のコンポーネントに閉じ込める
- canvas の中身はスクリーンリーダーに伝わらない。チャートの要点(高値を超えた時刻など)を文字でも出す

## 確認したこと、していないこと

- 確認した: Lightweight Charts のライセンスと帰属表示の方法(npm と README、2026-11-17)。npm の表示は 5.0.8
- 確認していない: Recharts の最新の安定版、shadcn/ui の Chart コンポーネントが対応する Recharts の版。導入時に確認する

## 追記(2026-11-20、T10)

- 入れた版は lightweight-charts 5.3.0。帰属表示(attributionLogo)は、部品の中の画像と、TradingView のサイトへのリンクでできている。外から何も読み込まず、部品が自分から通信することもない(T10 のセキュリティレビューで、部品のコードを読んで確かめた)
- リンクは、利用者が押した時だけ外のサイトを新しいタブで開く。リンクの URL には、このパソコンのホスト名と画面のパス(例: 127.0.0.1/trades)が入る。接続用キーや記録は入らない。外との通信先を Alpaca だけにする決まり(ADR-0006)の例外として、ここに記録する
