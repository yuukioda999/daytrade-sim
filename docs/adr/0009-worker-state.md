# ADR-0009: 自動売買のプロセスの記録の作り方

- 状態: 承認済み(2026-11-20、人間が推奨の A を採用)
- 日付: 2026-11-20

## 背景

T9 で、自動売買のプロセス(ワーカー、ADR-0007)を作る。SPEC-003 で次のことを決めている。

- 同じ足を2回処理しても、記録は1回だけ(定義 10、AC-003-09)
- 止まっていた時間は、再び動いた時に足を取り直して順に処理し、止まっていなかった場合と同じ記録を作る。あとから処理した記録には印を付ける(定義 11、AC-003-10)
- 自動売買を OFF にすると、次の足から新しく買わない(SPEC-006 AC-006-01)
- 元手と為替の変更は次の取引日から(定義 12)

データは15分遅れで届くので、ワーカーは1分ごとに「今日の取引開始から16分前まで」の5分足を4銘柄分取り、まだ処理していない足を処理する。4銘柄で毎分4回の通信になり、無料の上限(毎分200回)に収まる。

## 選択肢と評価

| 案 | 評価 |
|---|---|
| A: その日を足から作り直す。毎回、保存した今日の足を最初から順に、SPEC-002 と SPEC-003 の純粋関数に通し、今日の記録を作り直して置き換える | 同じ足を何度処理しても結果は同じになる(定義 10 を作りで満たす)。止まっていた分の取り直しも、足を埋めて作り直すだけ(定義 11)。過去データで試す(T11)も同じ処理を過去の日に使える(ADR-0007 の狙い)。OFF にした時刻と、足を受け取った時刻を記録しておく必要がある(作り直す時に、その時の ON / OFF と「あとから処理」の印を決めるため)。毎回1日分(最大 78本 × 4銘柄)を計算し直すが、量は小さい |
| B: 状態を少しずつ進める。持っている株、今日の損益などの状態を DB に保存し、新しい足だけを処理して状態を更新する | 実際の売買の流れに近い。処理済みの足の印、途中で止まった時の状態の食い違い、取り直しの順番を自分で守る必要があり、間違えると記録が二重になったり抜けたりする。過去データで試す処理は別に要る |

## 決定

A(人間が 2026-11-20 に推奨を採用)。

## 理由

- 定義 10 と 11 を、足を保存して作り直すだけで満たせる。状態の食い違いが起きない
- T4 で作った純粋関数(enter、processBar、settleSessionEnd、startDay)と、T3 の evaluateBar をそのまま使える
- T11 の「過去データで試す」と同じ処理になる

## 影響

- 足に「受け取った時刻」を持たせる。足の始まりから30分(足の長さ 5分 + 遅れ 15分 + 余裕 10分)より後に受け取った足で起きた売買に「あとから処理」の印を付ける。動いた日の足で受け取った時刻がない足(過去データの取得で入れた足)も印を付ける(2026-11-20、T9 のレビュー 5 を受けて人間が推奨を採用)
- 自動売買の ON / OFF は、変えた時刻の履歴を持つ(同じ値を保存し直した時は書かない)。作り直す時は、その足を受け取った時刻の ON / OFF を使う(2026-11-20、T9 のレビュー 2 を受けて人間が推奨を採用。足の時刻と比べると、データの遅れの分、OFF にしたあとも最大約20分買うため)。受け取った時刻がない足は、作り直している時刻で決める
- その日に使う元手と為替は、その日を始める時に money_settings に保存する(SPEC-006 決めたこと 6)
- ワーカーの動いた時刻と、最後に足を受け取った時刻を DB に書き、画面(T10)が「自動売買が止まっています」(AC-007-09)と「最後にデータを受け取った時刻」(AC-007-08)を出せるようにする
- 取引量の増加の条件(SPEC-002)には過去20取引日の足が要る。ワーカーは日を始める時に、足りない日の足を Alpaca から取って埋め、その日の基準に使う日(直前の20取引日のうち取り終えた日)を決めて保存する。その日の間は変えない(2026-11-20、T9 のレビュー 3 を受けて人間が推奨を採用。あとから取れて記録が過去にさかのぼって変わるのを防ぐ)

## 止まっていた日の扱い(2026-11-20、人間が推奨を採用)

SPEC-003 定義 11(止まっていた間を取り直して記録する)と、SPEC-004(自動売買が止まっていた日は行を作らない)が食い違っていた。取り直して記録するのは、ワーカーが動いた日の、止まっていた時間だけにする。丸1日動かなかった日は記録しない。値動きそのものは、取引量の基準のために取って埋める。SPEC-003 定義 11 に追記した

## 確認したこと、していないこと

- 確認した: 無料のプランで、全市場の5分足を16分前まで取れること(2026-11-20、人間のキーで「接続を確かめる」が成功。ADR-0005 に追記)
- 確認していない: 取引時間中に、取引開始から16分前までの足が毎分欠けずに届くか
